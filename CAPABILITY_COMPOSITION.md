# Capability Composition

## Composition unit

The fundamental unit under investigation is not the repository. It is the capability.

Example:

Capability A
+
Capability B
+
Capability C
+
composition mechanism
=
candidate composed capability

## Composition patterns

- sequential
- parallel
- feedback
- debate
- verification loop
- specialist delegation
- reciprocal refinement
- evidence-mediated collaboration

## Important boundary

A composition may create a new workflow without creating a new intelligence.

The distinction must be established experimentally.

## Baseline requirement

Every claimed emergent capability should be compared with:

- the strongest relevant individual-system baseline
- the relevant non-composed workflow
- the same task without the proposed composition mechanism

The purpose is to measure what the composition actually contributes.
