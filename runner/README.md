# KSI Super Intelligence Runner v0.1

## Governed Cognitive Execution Kernel

Runner v0.1 is the execution kernel for increasingly capable intelligence under externally governed human authority.

It does not claim superintelligence. It establishes the control boundary in which capability can scale without capability becoming authority.

### Core invariant

Every consequential action follows:

REQUEST -> INTERPRET -> CLASSIFY -> CAPABILITY CHECK -> AUTHORIZATION CHECK -> EXECUTE/STOP -> OBSERVE -> VERIFY -> EVIDENCE

There is no alternate execution path around the authorization gateway.

### Authority boundary

- Human authority is external to the runner.
- The runner cannot grant itself authority.
- Capability, intelligence, autonomy, emergence, success, or qualification never imply authority.
- Protected governance changes require external human authorization.
- Qualification remains external to the runner.
- Historical evidence is append-only and cannot be rewritten to manufacture success.

### v0.1 scope

Included:
- objective and planning interfaces
- capability-aware execution
- authorization gateway
- bounded tool execution
- epistemic state tracking
- provenance-preserving evidence records
- human escalation
- Kronos/M02 integration interfaces
- adversarial governance tests

Not included:
- a claim of superintelligence
- unrestricted arbitrary-code execution
- self-modifying governance
- self-certification
- autonomous authority
