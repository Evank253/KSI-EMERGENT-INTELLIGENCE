# Emergent Intelligence Experiment Protocol

## Principle

Never declare emergence from a single successful demonstration.

## Procedure

1. Select participating systems and exact versions.
2. Identify the capabilities being composed.
3. Define the target task before execution.
4. Establish isolated baselines for each relevant system.
5. Establish an ordinary-orchestration baseline where appropriate.
6. Execute the composed mechanism.
7. Capture complete provenance and observations.
8. Repeat across independent trials.
9. Test failure and boundary conditions.
10. Compare against baselines.
11. Attempt reproduction.
12. Record contradictions and unresolved questions.

## Required evidence

- system versions/commit SHAs
- capability identifiers
- bridge version
- test inputs
- environment
- outputs
- timing/resource measurements where relevant
- logs
- artifacts
- reproduction results
- failure cases

## Disposition

Results may be recorded as:

- DEMONSTRATED
- PARTIALLY_DEMONSTRATED
- EVIDENCE_INSUFFICIENT
- CONTRADICTED
- NOT_MEASURED
- UNABLE_TO_REPRODUCE
- REQUIRES_FURTHER_TESTING
