# Emergence Model

## Research question

Can independently developed intelligent systems, connected through explicit capability-composition mechanisms, produce reproducible higher-order capabilities while each system remains independently bounded?

## Hypothesis levels

### H0 — No compositional gain
The combined system provides no reproducible capability beyond the relevant individual baselines.

### H1 — Functional composition
The combined system performs a workflow requiring multiple capabilities, but the result remains explainable as ordinary orchestration.

### H2 — Higher-order capability
The combined system demonstrates a reproducible capability that depends on interaction among systems and cannot be adequately reproduced by any single participating system under the same conditions.

### H3 — Higher-order intelligence hypothesis
Repeated evidence supports a broader class of adaptive, generalizable cross-system behavior. This level requires substantially stronger evidence and independent reproduction.

These are research hypotheses, not qualification labels.
